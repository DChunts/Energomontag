# Энергомонтаж

Статический сайт компании для домена `energomontag51.ru`, перенесённый из архива `energomontag51-regru-1.zip`. HTML, CSS и изображения находятся в корне репозитория.

## Локальный запуск

Нужен Python 3. Установка зависимостей, сборка, база данных и секреты не требуются.

Из корня репозитория выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/` в локальном браузере. В облачной среде этот адрес используется для внутренних проверок:

```sh
curl --fail http://127.0.0.1:8000/
curl --fail http://127.0.0.1:8000/styles.css
```

Остановка сервера: `Ctrl+C`.

## Размещение на хостинге

Исходная инструкция для REG.RU сохранена в файле `ИНСТРУКЦИЯ.txt`. Файл `index.html` должен находиться в корне сайта. Настройки `.htaccess` применяются на Apache; сервер Python используется только для разработки и не обрабатывает этот файл.

Контактные ссылки используют телефон и электронную почту. Формы отправки заявки и её серверного обработчика в этой версии нет.
